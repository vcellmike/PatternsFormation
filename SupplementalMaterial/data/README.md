## The rows in the .pkl dataframes

The underlying measurement definitions follow ImageJ/Fiji Analyze > Set Measurements..., Analyze Particles..., and Summarize; the _inverted fields represent the same measurements computed on an inverted image.

| Column                     | Description                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `num_spots`                | Number of detected spots/particles in the standard analysis.                               |
| `Mean`                     | Mean gray value inside detected spots; average pixel intensity within the ROI.             |
| `Median`                   | Median pixel intensity inside detected spots.                                              |
| `Area_mean`                | Mean particle area across detected spots.                                                  |
| `Area_std`                 | Standard deviation of particle area across detected spots.                                 |
| `X_mean`                   | Mean X coordinate of spot centroids.                                                       |
| `X_std`                    | Standard deviation of centroid X coordinates.                                              |
| `Y_mean`                   | Mean Y coordinate of spot centroids.                                                       |
| `Y_std`                    | Standard deviation of centroid Y coordinates.                                              |
| `Perim._mean`              | Mean perimeter; average boundary length of detected spots.                                 |
| `Perim._std`               | Standard deviation of spot perimeters.                                                     |
| `BX_mean`                  | Mean X coordinate of the upper-left corner of the bounding rectangle.                      |
| `BX_std`                   | Standard deviation of bounding-rectangle X coordinates.                                    |
| `BY_mean`                  | Mean Y coordinate of the upper-left corner of the bounding rectangle.                      |
| `BY_std`                   | Standard deviation of bounding-rectangle Y coordinates.                                    |
| `Width_mean`               | Mean width of the spot bounding rectangles.                                                |
| `Width_std`                | Standard deviation of bounding-rectangle widths.                                           |
| `Height_mean`              | Mean height of the spot bounding rectangles.                                               |
| `Height_std`               | Standard deviation of bounding-rectangle heights.                                          |
| `Major_mean`               | Mean major-axis length of the best-fit ellipse.                                            |
| `Major_std`                | Standard deviation of major-axis lengths.                                                  |
| `Minor_mean`               | Mean minor-axis length of the best-fit ellipse.                                            |
| `Minor_std`                | Standard deviation of minor-axis lengths.                                                  |
| `Angle_mean`               | Mean angle of the fitted ellipse major axis relative to the image X-axis.                  |
| `Angle_std`                | Standard deviation of fitted-ellipse angles.                                               |
| `Circ._mean`               | Mean circularity, `4π × Area / Perimeter²`.                                                |
| `Circ._std`                | Standard deviation of circularity.                                                         |
| `Feret_mean`               | Mean Feret diameter; average maximum caliper diameter.                                     |
| `Feret_std`                | Standard deviation of Feret diameter.                                                      |
| `IntDen_mean`              | Mean integrated density, equivalent to `Area × Mean Gray Value`.                           |
| `IntDen_std`               | Standard deviation of integrated density.                                                  |
| `%Area_mean`               | Mean area fraction; average percentage of thresholded or non-zero pixels in the selection. |
| `%Area_std`                | Standard deviation of area fraction.                                                       |
| `RawIntDen_mean`           | Mean raw integrated density; average sum of pixel values within each spot.                 |
| `RawIntDen_std`            | Standard deviation of raw integrated density.                                              |
| `FeretX_mean`              | Mean X coordinate of the starting point of the Feret diameter line.                        |
| `FeretX_std`               | Standard deviation of FeretX.                                                              |
| `FeretY_mean`              | Mean Y coordinate of the starting point of the Feret diameter line.                        |
| `FeretY_std`               | Standard deviation of FeretY.                                                              |
| `FeretAngle_mean`          | Mean angle of the Feret diameter relative to the image X-axis.                             |
| `FeretAngle_std`           | Standard deviation of Feret-angle values.                                                  |
| `MinFeret_mean`            | Mean minimum caliper diameter.                                                             |
| `MinFeret_std`             | Standard deviation of minimum caliper diameter.                                            |
| `AR_mean`                  | Mean aspect ratio of the fitted ellipse, `Major / Minor`.                                  |
| `AR_std`                   | Standard deviation of aspect ratio.                                                        |
| `Round_mean`               | Mean roundness, `4 × Area / (π × Major²)`.                                                 |
| `Round_std`                | Standard deviation of roundness.                                                           |
| `Solidity_mean`            | Mean solidity, `Area / ConvexArea`.                                                        |
| `Solidity_std`             | Standard deviation of solidity.                                                            |
| `num_spots_inverted`       | Number of detected spots/particles in the inverted-image or inverted-mask analysis.        |
| `Mean_inverted`            | Mean gray value inside detected spots in the inverted analysis.                            |
| `Median_inverted`          | Median pixel intensity inside detected spots in the inverted analysis.                     |
| `Area_inverted_mean`       | Mean particle area across detected spots in the inverted analysis.                         |
| `Area_inverted_std`        | Standard deviation of particle area in the inverted analysis.                              |
| `X_inverted_mean`          | Mean X coordinate of spot centroids in the inverted analysis.                              |
| `X_inverted_std`           | Standard deviation of centroid X coordinates in the inverted analysis.                     |
| `Y_inverted_mean`          | Mean Y coordinate of spot centroids in the inverted analysis.                              |
| `Y_inverted_std`           | Standard deviation of centroid Y coordinates in the inverted analysis.                     |
| `Perim._inverted_mean`     | Mean perimeter in the inverted analysis.                                                   |
| `Perim._inverted_std`      | Standard deviation of perimeter in the inverted analysis.                                  |
| `BX_inverted_mean`         | Mean bounding-rectangle upper-left X coordinate in the inverted analysis.                  |
| `BX_inverted_std`          | Standard deviation of bounding-rectangle X coordinates in the inverted analysis.           |
| `BY_inverted_mean`         | Mean bounding-rectangle upper-left Y coordinate in the inverted analysis.                  |
| `BY_inverted_std`          | Standard deviation of bounding-rectangle Y coordinates in the inverted analysis.           |
| `Width_inverted_mean`      | Mean bounding-rectangle width in the inverted analysis.                                    |
| `Width_inverted_std`       | Standard deviation of bounding-rectangle widths in the inverted analysis.                  |
| `Height_inverted_mean`     | Mean bounding-rectangle height in the inverted analysis.                                   |
| `Height_inverted_std`      | Standard deviation of bounding-rectangle heights in the inverted analysis.                 |
| `Major_inverted_mean`      | Mean fitted-ellipse major-axis length in the inverted analysis.                            |

| `Minor_inverted_mean`      | Mean fitted-ellipse minor-axis length in the inverted analysis.                            |

| `Feret_inverted_mean`      | Mean Feret diameter in the inverted analysis.                                              |
