# SupplementalMaterial

This directory contains the complete supplemental computational material supporting the analysis of reaction–diffusion–based pigmentation patterns.  
It includes machine-learning notebooks, trained models, derived datasets, and visualization outputs used for clustering, classification, and parameter–feature analysis.

The materials here are intended to support reproducibility and inspection of the analyses reported in the associated manuscript.

---

## Directory structure overview

- Jupyter notebooks implementing clustering, visualization, and parameter estimation.

- `data/`  
  Derived datasets, trained models, and classification outputs used by the notebooks.

- `output_images/`  
  Figures and visualization outputs generated by analysis notebooks.

---

## `data/` folder contents

The `data` directory contains serialized datasets, trained model artifacts, and intermediate analysis results.  
All files are read-only analysis outputs and should not be manually edited.

### Model performance and evaluation

- **`R2_Values`**  
  Stores coefficient-of-determination (R²) values from regression or predictive model evaluations, used to quantify goodness-of-fit between predicted and observed quantities.

---

### Unclassified feature datasets (`.pkl`)

These files contain feature vectors extracted from simulated images without manual class labels.  
They are used for clustering, prediction, or post hoc classification.

- **`unclassified_features_39517.pkl`**  
  Feature dataset containing 39,517 unclassified samples.
---

### Clustering results on unclassified data

These datasets store clustering assignments applied to unclassified feature sets.

- **`unclassified_features_39517_KM_classes_5_s42.pkl`**  
  K-means clustering results with 5 clusters (seed = 42).

- **`unclassified_features_39517_KM_classes_6_s42.pkl`**  
  K-means clustering results with 6 clusters (seed = 42).

- **`unclassified_features_39517_KM_classes_7_s42.pkl`**  
  K-means clustering results with 7 clusters (seed = 42).


---

### XGBoost-related artifacts

- **`real_df_xgboost.pkl`**  
  Feature dataframe formatted for XGBoost training or inference.

- **`unclassified_features_39517_s42_XGB.model`**  
  Trained XGBoost model (seed = 42) applied to the unclassified feature dataset.

---

### Parameter scan data

- **`single_param_scans.pkl`**  
  Results from single-parameter variation experiments, used to analyze sensitivity of pattern features to individual reaction–diffusion parameters.

---

### `output_images/` folder

This directory contains figures generated by notebooks, including:
- clustering visualizations,
- feature–parameter plots,
- classification result summaries.

These images are derived artifacts and can be regenerated by rerunning the corresponding notebooks.
